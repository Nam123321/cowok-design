# cowok.ai Brand & Product Guideline v4.0

## Category
**AI-native Work OS / Human + Agent Workspace**

## Central idea
**Human judgment. Agent execution. One workflow.**

## Primary descriptor
**Human + AI. One Workflow.**

## Identity
- Logo: Option 3 Refined — Human + Agent
- Wordmark: Customized Geist Option C
- Typography: Geist
- Iconography: Hybrid v2.0

## Product character
Professional, trusted, calm, operational, human-centered, AI-native and designed for long-session daily work.

## Visual principle
**Warm in light. Calm in dark. Quiet by default. Color only when meaningful.**

## Themes
- Warm Light — primary; no Low-chroma
- Focus Light — dim/soft light; no Low-chroma
- Night — deep warm/charcoal navy
- Night Low-chroma — optional semantic remap

## Human / Agent semantic rule
- Human Blue is semantic, not generic CTA.
- Agent Orange is semantic, not generic warning or generic CTA.
- Large workspace surfaces remain neutral.

## Workflow-first AI UX
Canonical lifecycle:
`Request → Interpret → Draft → Review → Execute → Report`

Critical:
**Draft ≠ Approved ≠ Executed**

## Source hierarchy
1. approved master assets
2. machine-readable tokens / manifests
3. DESIGN.md
4. module specification
5. AGENTS.md
6. HTML references
7. visual boards
