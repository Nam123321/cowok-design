# Tech Stack Specification: cowok-design (UI/UX OS — FlowForge Harness OS)

## 1. Bảng Công nghệ Chuẩn hóa (Day-1 Rust Core + React 19 Hybrid Stack)

| Phân hệ | Công nghệ Lựa chọn | Ràng buộc & Chỉ số Kỹ thuật (Zero-Trust Invariants) |
| :--- | :--- | :--- |
| **Core Harness Daemon & API** | **Rust 2024 + Axum 0.8 + Tokio** | Triển khai bằng Rust ngay từ Ngày 1. Idle RAM $\le 35\text{ MB}$, khởi động $< 15\text{ ms}$. |
| **AST Linter, Patcher & Constraint Engine** | **Rust `crates/constraint-engine` (`oxc` / Rule Engine)** | Quét AST và vá `data-ff-id` $< 1\text{ ms}$. Thực thi cấu hình ràng buộc theo từng dự án (`constraint_profiles` / `constraint_rules`). |
| **Domain Core & Type Sync** | **`crates/domain` (`serde` + `ts-rs` + `packages/shared-types`)** | 100% kiểu dữ liệu biên giới đồng bộ `ts-rs` + Zod validation (`SafeJsInteger`), thống nhất PascalCase/snake_case serialization. |
| **Autonomous Fleet & PTY Hub (`cowok` & `advisor`)** | **Rust `crates/bot-fleet` + `notify` Live `SpecWatcher`** | Background `SpecWatcher` khởi động cùng `harness-daemon`, phát hiện stale SHA-256 trên đĩa và đồng bộ `project_specs`. |
| **Plugin Repackager & Cron Scheduler** | **Rust `crates/plugin-host` (`agentskills.io` Parser)** | Chuẩn hóa gói kỹ năng thành `SKILL.md` + `plugin.json`; quản lý vòng đời 6 trạng thái. |
| **Design-Only REA Forge** | **Rust `crates/rea-bridge`** | Chỉ trích xuất Design DNA (màu, chữ, bố cục, trạng thái); lọc bỏ 100% logic backend và khóa bí mật. |
| **Local Database & Spec Vault** | **Rust `crates/spec-registry` (`rusqlite` SQLite WAL — V1..V4)** | Single-authority `.cowok-design/cowok-design.sqlite3` (`0700/0600`), OCC atomic SQL-before-disk, đồng bộ 2 chiều với `.cowok-design/specs/`. |
| **Universal Open MCP Server** | **Rust `crates/mcp-gateway` (JSON-RPC 2.0 `stdio` + HTTP/SSE)** | Phơi bày công cụ `design.*` chia theo 4 tầng quyền hạn (`READ_ONLY`, `AGENT_FACING`, `AGENT_PROPOSE_ONLY`, `HUMAN_ONLY`). |
| **Frontend Workbench & In-Process Guarded BFF** | **Vite v8 + React 19 SPA + `src/lib/vite-bff-plugin.ts` + `packages/ui-shell`** | 100% `tokens.css` (Zero Tailwind, Zero Amber), `guardedRoute({ body: ZodSchema })` (không `forwardDirect`), typed SDK trong `src/api/*.ts`. |
