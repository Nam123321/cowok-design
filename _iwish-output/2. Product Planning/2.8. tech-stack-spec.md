# Tech Stack Specification: cowok-design (UI/UX OS — FlowForge Harness OS)

## 1. Bảng Công nghệ Chuẩn hóa (Day-1 Rust Core + React 19 Hybrid Stack)

| Phân hệ | Công nghệ Lựa chọn | Ràng buộc & Chỉ số Kỹ thuật (Zero-Trust Invariants) |
| :--- | :--- | :--- |
| **Core Harness Daemon & API** | **Rust 2024 + Axum 0.8 + Tokio** | Triển khai bằng Rust ngay từ Ngày 1. Idle RAM $\le 35\text{ MB}$, khởi động $< 15\text{ ms}$. |
| **AST Linter, Patcher & Constraint Engine** | **Rust `oxc` (Oxidation Compiler) + `tree-sitter`** | Quét AST và vá `data-ff-id` $< 1\text{ ms}$. Thực thi cấu hình ràng buộc theo từng dự án (`PROJECT_CONSTRAINTS`). |
| **`JEV — TypeSafe` Acceleration Engine** | **`crates/jev-engine` (Rust Deterministic Primitives)** | `Jev Choice` ($<2\text{ ms}$), `Jev Noul` ($<1\text{ ms}$), `Speculative Multi-Head`, `window.__jevFast`, `StaleFile` OCC, `3-Strike Breaker`. |
| **Autonomous Fleet & PTY Hub (`cowok` & `advisor`)** | **Rust `portable-pty` + `notify` File Watcher** | Điều phối bởi `cowok` và `advisor`; tiêm `$UIUX_LIVE_SPEC` cập nhật lên Canvas trong $<50\text{ ms}$ kèm hoàn tác `Cmd+Z`. |
| **Plugin Repackager & Cron Scheduler** | **Rust `tokio-cron-scheduler` + `git2` + `agentskills.io` Parser** | Chuẩn hóa repo GitHub thành `SKILL.md` (3 tầng Progressive Disclosure) + `plugin.json`; tự động quét cập nhật định kỳ. |
| **Design-Only REA & Awesome-RE Forge** | **`crates/design-rea-forge` (DOM/CSS/Token Extractor)** | Chỉ trích xuất Design DNA (màu, chữ, bố cục, trạng thái); lọc bỏ 100% logic backend và khóa bí mật. |
| **Local Database & Spec Vault** | **Rust `rusqlite` (SQLite WAL mode — 16 Tables)** | Nhúng trực tiếp trong binary Rust, đồng bộ 2 chiều với `.uiux-os/`. |
| **BYOS Process Sandbox & Tool Forging** | **Rust `tokio::process` + `nix` (POSIX `setpgid`/`killpg`)** | Prompt staging qua file tạm `0600` + `stdin`; cô lập script tự rèn trong sandbox giới hạn đường dẫn và thời gian. |
| **Universal Open MCP Server** | **Native Rust JSON-RPC 2.0 (`stdio` + `Streamable HTTP/SSE`)** | Phơi bày 12 công cụ `design.*` chia theo 4 tầng quyền hạn cho Cowok.ai, Claude, Codex, Antigravity. |
| **Cross-Language Type Sync** | **`serde` + `ts-rs` + `schemars`** | Tự động xuất TypeScript interfaces (`.d.ts`) và JSON Schemas từ `crates/domain`. |
| **Frontend Workbench & Presentation Studio** | **Vite v8 + React 19 SPA + True 2D SVG Cubic Bezier DAG (`DagCanvas2D`)** | Giao diện Workbench dùng 100% `tokens.css` (chuẩn tối giản `cowok.ai`, Zero Amber) và 143 Brand Icons (`cowok-brand-product-system-v4.3` Flagship Preset). |
| **4-Channel Distribution** | **Single Binary CLI + `Tauri v2` Desktop + Cowok Plugin + OCI Docker** | Đóng gói linh hoạt cho cả cá nhân, đội nhóm và tích hợp doanh nghiệp. |
