# 2.12. Canonical API & Universal MCP Tool Registry — UI/UX OS (FlowForge Harness OS)

## 1. Danh mục HTTP REST & Loopback Auth Endpoints (`crates/harness-daemon` — `/api/v1/*`)

Tất cả các endpoint dưới đây ngoại trừ `GET /api/v1/health` (chỉ trả status/version an toàn, **tuyệt đối không rò rỉ `daemon_nonce` hay `hmac_key_hex`**) và `POST /api/v1/auth/local-session` (chỉ cấp session khi xác thực `origin`/`host`/`bootstrap_token`) đều bắt buộc vượt qua **Cryptographic Dual-Ingress Auth** (`verify_hmac_v2` + `record_nonce_once` hoặc scoped `X-Cowok-Session-Token`). Cấm tuyệt đối header-presence bypass (`is_loopback_hmac`) và `forwardDirect` trong Vite BFF (`src/lib/vite-bff-plugin.ts`).
