# 2.12. Canonical API & Universal MCP Tool Registry — UI/UX OS (FlowForge Harness OS)

## 1. Danh mục HTTP REST & Loopback Auth Endpoints (`crates/harness-daemon` `/api/v1/*` + Vite BFF `/api/*`)

Tất cả các endpoint dưới đây ngoại trừ `GET /api/v1/health` (chỉ trả status/version an toàn, **tuyệt đối không rò rỉ `daemon_nonce` hay `hmac_key_hex`**) và cặp session bootstrap (`POST /api/auth/local-session` trên Vite BFF & `POST /api/v1/auth/local-session` trên Axum — chỉ cấp session khi xác thực `Host`+port/`Origin`/`Sec-Fetch-Site` cùng capability proof như daemon nonce hoặc same-origin boot capability token, **cấm tuyệt đối cấp `'editor'`/`'admin'` không kiểm chứng**) đều bắt buộc vượt qua **Cryptographic Dual-Ingress Auth** (`verify_hmac_v2` + `record_nonce_once` hoặc scoped `X-Cowok-Session-Token`). Vite BFF (`src/lib/vite-bff-routes.ts`) thực thi in-process các adapter `src/app/api/**/route.ts` và `proxyRoute()` (`forwardGuardedDaemon` dịch `/api/* -> /api/v1/*`); mọi `proxyRoute` mutating (`POST`/`PUT`/`PATCH`) bắt buộc khai báo Zod `body` schema hoặc passthrough JSON tường minh để không làm rơi payload. Cấm tuyệt đối header-presence bypass (`is_loopback_hmac`) và `forwardDirect`.
