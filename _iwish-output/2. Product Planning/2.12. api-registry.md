# 2.12. Canonical API & Universal MCP Tool Registry — UI/UX OS (FlowForge Harness OS)

## 1. Danh mục HTTP REST & SSE Endpoints (`crates/harness-daemon` — `/api/v1/*`)

| Nhóm | Method | Endpoint Path | Mô tả Nghiệp vụ |
| :--- | :---: | :--- | :--- |
| **Specs & Constraints** | `POST` | `/api/v1/projects` | Khởi tạo dự án từ Brief/Repo và thiết lập `PROJECT_CONSTRAINTS` (mặc định preset `cowok-brand-v4.3` hoặc cấu hình riêng). |
| **Specs & Constraints** | `POST` | `/api/v1/projects/:id/intake` | Phân tích PRD ngoài và sinh Bộ 9 Foundational Project Context Specs (`SPEC-01` .. `SPEC-09`). |
| **Specs & Constraints** | `PUT` | `/api/v1/projects/:id/constraints` | Cập nhật cấu hình ràng buộc của dự án (CSS policy, `tokens.css`, `icon-manifest.json`, WCAG contrast). |
| **Flow & SDI Core** | `GET` | `/api/v1/projects/:id/flows` | Lấy đồ thị `ScreenState` (`route + fixtureRef + viewport`) và `Transition` kèm bình luận neo (`ANCHORED_COMMENTS`). |
| **Flow & SDI Core** | `POST` | `/api/v1/projects/:id/intents` | Biên dịch yêu cầu tự nhiên thành `DesignIntentV1` (SDI) qua `Jev Choice` + `Speculative Multi-Head`; trả về 2–3 phương án nếu `ambiguityScore >= 0.45`. |
| **Flow & SDI Core** | `POST` | `/api/v1/projects/:id/proposals/:pid/apply` | Kiểm tra cổng `E1..E4` và áp dụng `ChangeProposal` hoặc khôi phục (`revert`) về `VersionSnapshot`. |
| **Flow & SDI Core** | `PATCH` | `/api/v1/projects/:id/patch-ff` | Vá trực tiếp nội dung hoặc biến CSS qua `data-ff-id` trong `<1ms` bằng `oxc` AST Patcher (0 token). |
| **16:9 Deck & CMS** | `POST` | `/api/v1/projects/:id/presentations` | Khởi tạo bài thuyết trình/báo cáo HTML `16:9` kế thừa Brand Guideline của dự án. |
| **16:9 Deck & CMS** | `PATCH` | `/api/v1/presentations/:did/slides/:sid/cms` | Đồng bộ `<16ms` thay đổi chữ/số liệu từ khung CMS bên trái sang slide 16:9 bên phải. |
| **16:9 Deck & CMS** | `POST` | `/api/v1/presentations/:did/export` | Xuất bản file `.html` độc lập hoặc `.pdf` vector chuẩn `1920x1080`. |
| **Skills & REA Forge** | `POST` | `/api/v1/skills/repackage` | Đóng gói repo GitHub/workflow ngoài thành chuẩn `agentskills.io` (`SKILL.md` + `plugin.json`) và đăng ký lịch Cron Sync. |
| **Skills & REA Forge** | `POST` | `/api/v1/rea-forge/extract` | Phân tích ngược URL/repo tham khảo trong ranh giới **Design-Only** để trích xuất Design DNA thành skill. |
| **`cowok` & `advisor` Fleet** | `POST` | `/api/v1/fleet/cowok/dispatch` | Giao việc cho **`cowok` (`Cowok Orchestrator`)** điều phối các Execution Agents (`Claude`, `Codex`, `AGY`, `Grok`, `Muse`, `Duet`, `Dot`) hoặc mở đấu trường **Tournament Mode**. |
| **`cowok` & `advisor` Fleet** | `POST` | `/api/v1/fleet/advisor/evolve` | Kích hoạt **`advisor` (`Advisor Agent`)** chạy vòng lặp tự tiến hóa 6 bước hoặc sinh `SKILL.md` / routine mới. |

## 2. Danh mục 12 Công cụ Universal MCP (`crates/mcp-server` — 4 Tầng Phân quyền)

| MCP Tool Name | Permission Tier | Chức năng phục vụ Cowok.ai, Claude, Codex, Antigravity & Execution Fleet |
| :--- | :---: | :--- |
| `design.get_project_context` | `READ_ONLY` | Đọc cấu hình dự án, `PROJECT_CONSTRAINTS`, và lát cắt JIT từ Bộ 9 Foundational Specs. |
| `design.inspect_screen_or_slide` | `READ_ONLY` | Đọc bản đồ `data-ff-id`, tọa độ `__jevFast`, bình luận neo và kết quả kiểm định 17 quy tắc. |
| `design.list_skills_and_components` | `READ_ONLY` | Tra cứu danh mục `SKILL.md` (`agentskills.io`) và `07_COMPONENT_REGISTRY` của dự án. |
| `design.compile_sdi_intent` | `AGENT_FACING` | Biên dịch yêu cầu thành `DesignIntentV1` và sinh phương án làm rõ trực quan (Visual Clarification). |
| `design.synthesize_project_specs` | `AGENT_FACING` | Sinh hoặc cập nhật Bộ 9 Foundational Project Context Specs từ PRD. |
| `design.patch_by_ff_id` | `AGENT_FACING` | Sửa trực tiếp văn bản/số liệu/token qua `data-ff-id` trong `<1ms` kèm kiểm tra `StaleFile` OCC. |
| `design.create_or_update_presentation` | `AGENT_FACING` | Tạo và cập nhật bộ slide thuyết trình / báo cáo HTML `16:9`. |
| `design.extract_design_rea` | `AGENT_FACING` | Chạy `Design-Only REA Forge` trích xuất Design DNA từ ứng dụng tham khảo thành `SKILL.md`. |
| `design.propose_flow_or_screen_change` | `AGENT_PROPOSE_ONLY` | Tạo `ChangeProposal` trên nhánh sandbox và kích hoạt cổng kiểm định độc lập `E1..E4`. |
| `design.run_tournament` | `AGENT_PROPOSE_ONLY` | Chạy đấu loại song song 2–3 phương án thiết kế và chấm điểm Rubric. |
| `design.apply_or_revert_proposal` | `HUMAN_ONLY` | Phê duyệt áp dụng (`Apply`) `ChangeProposal` vào nhánh chính hoặc khôi phục (`Revert`) lịch sử. |
| `design.export_deliverable` | `HUMAN_ONLY` | Xuất bản gói mã nguồn ZIP, tạo GitHub PR, hoặc xuất bản báo cáo `.html`/`.pdf`. |
