# Impeccable Polish Craft

## Purpose
Elevates functional layouts into crisp, high-craft interfaces by eliminating generic AI UI slop (card-in-card nesting, decorative purple gradients, placeholder text, harsh shadows) and applying targeted visual critique transformations. Absorbs and supersedes legacy design-vocabulary polish workflows into one canonical craft owner.

## Minimum Floor, Never Maximum Ceiling
Enforce the baseline craft floor below (consistent `4px/8px` spacing rhythm, WCAG AA+ contrast, visible `:focus-visible` states, crisp borders, and zero placeholders). Freely layer richer motion choreography, optical alignment tweaks, and bespoke craft refinements when the product tone warrants it.

## Operating Protocol
1. **Purge AI UI Slop:** Remove redundant outer wrappers, generic neon/indigo-to-violet hero gradients, emoji substitutes for real SVG iconography (`1.85px` monoline strokes), and ungrounded placeholder strings.
2. **Craft Vocabulary Transformations:** Translate human critique directly into deterministic token/CSS edits (`quieter` → soften border contrast & declutter chrome; `bolder` → sharpen typographic scale & focal contrast; `distill` → strip non-essential controls; `harden` → complete edge/error/focus states; `typeset` / `layout` / `animate` / `delight` as needed—open-ended, never capped to a fixed verb count).
3. **Spatial & Elevation Discipline:** Align all padding, gaps, and radii to a coherent modular scale (`4px / 8px / 12px / 16px / 24px`) with concentric border radii (`innerRadius = max(0, outerRadius - padding)`).
4. **Micro-Interaction & Focus Rigor:** Guarantee `150ms–220ms` ease-out transitions respecting `prefers-reduced-motion`, crisp `:focus-visible` rings (`var(--action-primary)`), and explicit `hover` / `active` / `disabled` / `aria-busy` states.
5. **Deep Reference:** Load [references/craft-refinement-checklist.md](references/craft-refinement-checklist.md) for optical alignment, concentric radii, and 3-tier craft audit criteria.
