# Multi-Dimensional User Simulation (`>= 8` Baseline Dimensions)

## Purpose
Audits completed screens, dashboards, and presentation decks from diverse human perspectives before handoff to surface cognitive friction, trust gaps, and edge-case breakdowns.

## Minimum Floor, Never Maximum Ceiling
The **8 core dimensions** below form the mandatory **Minimum Floor**. Whenever the product serves specialized users (e.g., bilingual/RTL operators, screen-reader power users, compliance auditors, field workers on spotty LTE, multi-tenant admins), synthesize additional custom personas and evaluate them alongside the 8 baseline dimensions.

## Baseline Simulation Dimensions (`>= 8`)
1. **First-Time Novice:** Can the user identify the primary goal and CTA within 3 seconds without a tutorial?
2. **Power User / Keyboard-Only:** Are shortcuts, logical tab order, focus visibility, and bulk actions frictionless?
3. **Low-Vision & Color-Blind:** Do WCAG AA/AAA contrast and non-color cues (labels, icons, patterns) preserve full meaning?
4. **Mobile Thumb-Zone & Touch:** Are primary controls comfortably reachable (`>= 44x44px` hit areas) without horizontal scroll?
5. **High-Stress / Error Recovery:** When an action fails, is user input preserved with a calm, actionable recovery path?
6. **Executive Skimmer:** In dashboards and decks, is the core conclusion legible in 3 seconds from Action Titles and KPIs alone?
7. **Skeptical Buyer / Trust:** Are permissions, data provenance, pricing, and destructive confirmations transparent and honest?
8. **Slow Network / Sparse & Extreme Data:** Do loading skeletons, empty states, and extreme counts (`0`, `1`, `10,000+` items) remain coherent?
9. **Custom Domain Personas (Open-Ended):** Add role-specific personas (e.g., RTL/CJK locale reviewer, compliance officer, analyst comparing scenarios) tailored to the active product brief.
