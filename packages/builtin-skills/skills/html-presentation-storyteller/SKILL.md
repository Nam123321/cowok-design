# HTML Presentation Storyteller Operating Skill

## 1. Overview
The `html-presentation-storyteller` skill formats product walkthroughs into 16:9 HTML slide decks. It enforces Stageshow's strict Word Budget (3–7 key words per slide), real device frames (`<Stage>`, `<Window>`, `<Phone>`), and causal mouse cursor animations (`Act` timeline).

## 2. Progressive Disclosure & Operation
- **Phase 1: Word Budgeting**: Distills message into 3-7 focal words; quiets secondary copy.
- **Phase 2: Device Framing**: Wraps live components inside crisp responsive shells.
- **Phase 3: Cursor Walkthrough**: Animates human hover and click interactions.
