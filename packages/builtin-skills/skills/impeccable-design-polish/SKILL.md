# Impeccable Design Polish Operating Skill

## 1. Overview
The `impeccable-design-polish` skill provides 24 precise design vocabulary verbs to transform and refine user interfaces: `bolder`, `quieter`, `distill`, `colorize`, `typeset`, `layout`, `animate`, `delight`, `overdrive`, `critique`, `audit`, `polish`, `harden`, `clarify`, `adapt`, `optimize`, `onboard`, `live`, `generate`, `shape`, `init`, `document`, `extract`.

## 2. Progressive Disclosure & Operation
- **Phase 1: Verb Interpretation**: Translates human design critique into concrete CSS/DOM changes.
- **Phase 2: Targeted Transformation**: E.g. `quieter` dims borders and reduces font weight; `bolder` emphasizes primary contrast.
- **Phase 3: Craft Verification**: Ensures zero token explosion and validates against baseline tokens.
