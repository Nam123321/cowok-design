# Business Requirements Distiller

## Purpose
Translates unstructured user ideas or stakeholder notes into a crisp domain model before any wireframe is drawn.

## Checklist
- Identify primary & secondary personas, core jobs-to-be-done (JTBD), and critical failure costs.
- Define measurable business KPIs (conversion, task completion time, error reduction) and explicit non-goals.
- Map required domain entities, permissions, and key user journeys using `catalogs/domain-blueprints.json`.
- Surface hidden edge cases (multi-currency, offline states, approval thresholds, audit trails) early in Phase 0.
