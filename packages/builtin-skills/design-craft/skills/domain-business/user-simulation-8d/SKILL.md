# 8-Dimensional User Simulation

## Purpose
Audits completed screens and presentation decks from 8 orthogonal human perspectives before handoff.

## The 8 Simulation Dimensions
1. **First-Time Novice:** Can the user identify the primary CTA within 3 seconds without a tutorial?
2. **Power User / Keyboard-Only:** Are shortcuts, tab order, and bulk actions frictionless?
3. **Low-Vision & Color-Blind:** Do WCAG AA/AAA contrast and non-color indicators preserve meaning?
4. **Mobile Thumb-Zone:** Are primary controls within comfortable reach (`>= 44x44px` tap targets)?
5. **High-Stress / Error Recovery:** When a request fails, is user input preserved with clear retry?
6. **Executive Skimmer:** In decks/dashboards, is the takeaway legible from headlines and KPIs alone?
7. **Skeptical Buyer / Trust:** Are pricing, permissions, and destructive confirmations transparent?
8. **Slow Network / Sparse Data:** Do skeleton states and empty states remain coherent and helpful?
