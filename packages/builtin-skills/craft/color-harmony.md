# Craft Rule: Color Harmony & OKLCH Semantics

## Principles
1. **Perceptual Uniformity**: Define palettes in OKLCH space ($L, C, H$) to avoid brightness jumps across hues.
2. **WCAG 2.2 AA Contrast**: Ensure minimum 4.5:1 contrast for body copy ($L \ge 4.5:1$) and 3.0:1 for large display headings.
3. **Accent Color Budget**: Brand accent color is reserved for primary focal actions and active indicators; never use accent colors as large background wallpapers.
4. **Surface Tinting**: Surfaces must derive from the warm/dim neutral base rather than pure monochromatic gray (`#808080`) or default indigo/purple AI slop gradients.
