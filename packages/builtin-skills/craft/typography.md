# Craft Rule: Typography & Typographic Scale

## Principles
1. **Typographic Scale**: Use a consistent Major Third (1.25) or Perfect Fourth (1.33) scale.
2. **Body Text**: Size 14-16px, line-height 1.4-1.6. Never use `line-height: 1.0` on body copy.
3. **Tabular Numerics**: Always use `font-variant-numeric: tabular-nums` or `font-feature-settings: 'tnum'` for prices, metrics, timestamps, and tables.
4. **Line Length**: Constrain long-form prose to 65-75 characters (`max-width: 68ch`).
5. **Font Pairing**: One expressive display font paired with one neutral, highly readable UI workhorse font.
