# cowok-host-spine (Canonical Host Orchestrator Spine)

## Purpose
Clean host-runtime successor to `cowok-design-opt`. Governs host-level orchestration inside the desktop/local-daemon workbench while delegating pure design & storytelling craft to `packages/design-craft` and verbatim `upstream-skills`.

## Core Laws
1. **SSOT & Dynamic Discovery Law:** Discover capabilities dynamically via `UnifiedSkillCatalog`; never hardcode static skill lists, model IDs, or demo identifiers. Load active project `tokens.css`, portal locks, and registered UI patterns before generating code or layouts.
2. **AppShell Lease & Fencing Law:** Respect active AppShell lease boundaries; never overwrite locked chrome without a matching `fencingToken`.
3. **2-Breakpoint Cache-Safe Progressive Disclosure:** Keep Zone 1 (System Identity + Tool Schemas + Tier-1 Skill Index `<= 100 tok`/skill + `DESIGN.md` hash) byte-invariant across turns; inject Tier-2 `SKILL.md` bodies and Tier-3 `references/*.md` lazily in Zone 2 Turn Tail.
4. **Dynamic Semantic Token Discipline:** Resolve CSS custom properties strictly from `tokens.css` (`--bg-workspace`, `--bg-surface`, `--text-primary`, `--action-primary`); zero raw hex leaks or Tailwind `dark:` utilities.
5. **Minimum Floor, Plain UX Copy & Human-Only Governance:** Treat baselines as floors (never ceilings), speak in plain domain language, and enforce `HUMAN_ONLY` approval on any LEARN promotion.
